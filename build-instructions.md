# Blantyre Health Hub Mobile App - Build Instructions

## 🚀 Complete Cross-Platform Mobile App

This is a complete React Native mobile app built with Expo that works on:
- ✅ **Android** (Google Play Store)
- ✅ **iPhone/iPad** (Apple App Store) 
- ✅ **Web** (Progressive Web App)
- ✅ **Windows** (via Expo for Windows)

## 📧 **Email Functionality**

The app sends registration emails **directly to healthhubconnect071@gmail.com** using:
- Native email composer on mobile devices
- Automatic email formatting with all user data
- Professional email templates
- Error handling and user feedback

## 🛠️ **Setup Instructions**

### 1. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 2. Start Development Server
\`\`\`bash
npm start
\`\`\`

### 3. Run on Different Platforms
\`\`\`bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
\`\`\`

## 📱 **Build for Production**

### Android APK/AAB
\`\`\`bash
# Install EAS CLI
npm install -g @expo/eas-cli

# Login to Expo
eas login

# Build Android
eas build --platform android
\`\`\`

### iOS App Store
\`\`\`bash
# Build iOS
eas build --platform ios
\`\`\`

### Web Deployment
\`\`\`bash
# Build web version
npm run build

# Deploy to Vercel/Netlify
\`\`\`
